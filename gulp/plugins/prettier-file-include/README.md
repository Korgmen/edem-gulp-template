Плагин Prettier для HTML с директивами gulp-file-include (`@@include`, `@@if`, `@@for` и другими).

Prettier разбирает директиву как обычный текст и склеивает соседние директивы в одну строку. Плагин перед разбором заменяет каждую директиву, стоящую на отдельной строке, HTML-комментарием, а при печати выводит её обратно в исходном виде. Закрывающая `}` блока `@@if` обрабатывается так же. Строки внутри `<script>` и `<style>` не затрагиваются.

Директивы внутри строки текста или атрибута (`class="navigation @@mod"`, `<title>@@title</title>`) Prettier форматирует как обычный текст — плагину они не нужны.

Подключается в `.prettierrc.json`: парсер `file-include-html` для файлов `src/html/**/*.html`.
