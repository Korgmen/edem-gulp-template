Плагин для svgo, который меняет чёрные значения атрибутов `fill` и `stroke` (`black`, `#000`, `#000000`, `rgb(0, 0, 0)`) на `currentColor`, чтобы цвет иконок из спрайта задавался CSS-свойством `color`.
Остальные цвета и `fill="none"` не меняются: многоцветные и контурные иконки отображаются как в макете.

Подключается в `gulp/tasks/svg.js` в список плагинов svgo. Инструкция по подготовке иконок и примеры вызова — в README шаблона, раздел «Генерация SVG-спрайта».
