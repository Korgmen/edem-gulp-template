# Edem Template
*Edem Template далее будет обозначаться как "шаблон"*

Gulp-шаблон для вёрстки: SCSS с каскадными слоями, JS-модули с ленивой загрузкой, SVG-спрайт, оптимизация изображений и шрифтов, выгрузка на сервер по SFTP, настройки и сниппеты VSCode.

Любая работа с новым и неизведанным должна начинаться с документации. Проблема лишь в том, что не каждая документация написана простым и понятным языком. Я постарался написать документацию так, как будто я сам впервые ее читаю, чтобы все было максимально понятно и не вызывало проблем при работе с шаблоном *(но это не точно)*.

## Быстрый старт

Нужны Node.js 24+ и pnpm.

	pnpm install --frozen-lockfile
	pnpm dev

| Команда | Что делает |
| :--- | :--- |
| `pnpm dev` | dev-сервер с пересборкой при изменениях, окружение `stage` |
| `pnpm build` | продакшн-сборка в `build/`, окружение `prod` |
| `pnpm build:stage` | продакшн-сборка с окружением `stage` |
| `pnpm dev:deploy` | dev-сервер и выгрузка изменённых файлов на сервер |
| `pnpm run deploy` | продакшн-сборка и выгрузка на сервер |
| `pnpm deploy:stage` | сборка `stage` и выгрузка на тестовый сервер |
| `pnpm lint` | ESLint, Stylelint и проверка форматирования |
| `pnpm format` | форматирование Prettier |
| `pnpm run demo:remove` | удаление стартовой страницы |
| `pnpm run example:remove` | удаление справочника компонентов |

Подробнее о каждой команде — в разделе [Сборка](docs/build.md).

## <h2 id="fork">Как форкнуть проект</h2>

Чек-лист первого часа на новом проекте. Пункты идут в порядке выполнения.

**Репозиторий и окружение**
- [ ] Создать репозиторий проекта из шаблона и добавить шаблон вторым remote — по нему подтягиваются обновления *([Версии шаблона и обновление форка](docs/build.md#versions))*.
- [ ] Переключиться на Node из `.nvmrc` и поставить зависимости: `pnpm install --frozen-lockfile`.
- [ ] В `package.json` поменять `name`, `description`, `version`, `repository`, `bugs` и `homepage` на данные проекта. Решить, нужен ли проекту `LICENSE.txt` шаблона.
- [ ] Импортировать профиль VSCode и установить рекомендованные расширения *([Интеграция зависимых файлов шаблона](docs/getting-started.md#интеграция-зависимых-файлов-шаблона))*.
- [ ] Проверить `browserslist` в `package.json` — по нему lightningcss и esbuild решают, какой синтаксис оставить.

**Содержимое шаблона**
- [ ] Удалить стартовую страницу: `pnpm run demo:remove`. Справочник компонентов удобно оставить до конца вёрстки и удалить `pnpm run example:remove` перед сдачей *([Стартовая страница и примеры компонентов](docs/getting-started.md#demo-example))*.
- [ ] Положить шрифты проекта в `src/fonts/` и подключить в `src/scss/base/fonts.scss` *([Шрифты](docs/assets.md#шрифты))*.
- [ ] Прописать палитру в `src/scss/base/colors.scss` *([Вызов цветов](docs/scss.md#вызов-цветов))*, эффекты и стили текста — в `src/scss/abstracts/`.
- [ ] Выгрузить иконки из макета в `src/img/icons/` *([Генерация SVG-спрайта](docs/assets.md#svg-generation))*.

**Мета-теги** — чанк `src/html/chunks/head.html` *([Мета-теги страницы](docs/html.md#html-head))*
- [ ] Заменить `favicon.svg` и `apple-touch-icon.png` в `src/root/`.
- [ ] Поставить цвета фона проекта в оба `theme-color`, язык сайта — в `og:locale`.
- [ ] Поправить `preload` под `.woff2` основного шрифта проекта.
- [ ] Когда известен домен — добавить `og:image` и `og:url` с абсолютными адресами.

**Выгрузка на сервер** *([Выгрузка на сервер](docs/deploy.md))*
- [ ] Переписать `deploy.config.js` под пути на сервере проекта.
- [ ] Скопировать `.env.example` в `.env`, заполнить доступы и отпечаток сервера `DEPLOY_HOST_FINGERPRINT`.
- [ ] Проверить список файлов без выгрузки: `pnpm deploy:stage --dry-run`.

**Проверка**
- [ ] `pnpm lint` и `pnpm build` проходят без ошибок.
- [ ] В `build/index.html` после `pnpm build` нет `noindex`, после `pnpm build:stage` — есть *([Окружение сборки](docs/build.md#окружение-сборки-stage-и-prod))*.
- [ ] Если репозиторий на GitHub — CI из `.github/workflows/ci.yml` запускается сам; для обновлений зависимостей подключить Renovate *([Автоматическая проверка и обновление зависимостей](docs/build.md#ci))*.
